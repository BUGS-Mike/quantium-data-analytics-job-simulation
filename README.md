# Quantium Data Analytics Job Simulation

## Project Overview
This project was completed as part of the Quantium Data Analytics Virtual Job Simulation program.

The objective of this project was to analyze retail transaction datasets and generate business insights related to customer purchasing behavior, trial store performance, and retail strategy.

---

## Project Tasks

### Task 1: Data Preparation and Customer Analytics
- Cleaned and processed retail transaction data
- Performed exploratory data analysis (EDA)
- Identified customer purchasing patterns
- Analyzed sales trends and customer segments

### Task 2: Experimentation and Uplift Testing
- Compared trial stores with control stores
- Measured sales performance and customer growth
- Evaluated store trial effectiveness

### Task 3: Analytics and Commercial Insights
- Created presentation slides for stakeholders
- Generated business recommendations
- Visualized insights using charts and reports
